# StructureRebuildNH

面向 GTNH 的 GT / StructureLib 蓝图附属模组，用于快速调试和修改多方块结构。

默认保持原生蓝图行为。创造模式下，将蓝图的 `rebuild` 信道设为 `1`，手持蓝图潜行右键控制器，即可先清理本次结构范围内的普通方块，再执行原生蓝图放置，无需为每台机器单独接入。移除该信道即可关闭重建。

预清空会跳过容器、配置白名单中的方块，以及其他已成型 GT 机器的结构范围。白名单可按模组或方块编辑，默认包含 AE、常见 AE 附属模组及储物模组。保护仅作用于预清空，后续原生放置仍可按新结构替换方块；生存模式与结构预览保持原有行为。
